# 🎓 AI Personal Exam Mentor System

## 📖 About the Project

AI Personal Exam Mentor System is a full-stack web application designed to help students prepare for exams in a smarter and more organized way. Instead of following a fixed study timetable, the system creates a personalized learning experience based on each student's exam, study time, and learning progress.

The application combines Artificial Intelligence with modern web technologies to provide intelligent study planning, doubt solving, progress tracking, quiz generation, and performance analysis in one platform.

Whether a student is preparing for college exams or competitive exams like UPSC, NEET, JEE, GATE, or Banking exams, the system helps them stay focused and improve their preparation.

---

# 🎯 Purpose

Many students struggle with:

- Not knowing what to study first.
- Poor time management.
- Forgetting completed topics.
- No proper study schedule.
- Difficulty identifying weak subjects.
- Lack of personalized guidance.

This project solves these problems by acting as a personal AI mentor that guides students throughout their exam preparation journey.

---

# 🚀 What This Project Does

The system allows students to:

- Create an account and securely log in.
- Enter their target exam and exam date.
- Set daily study hours.
- Generate a personalized study timetable.
- Track completed and pending topics.
- Chat with an AI assistant to clear doubts.
- Generate practice MCQs.
- View quiz scores and performance.
- Analyze strengths and weaknesses.
- Monitor study progress through dashboards.
- Receive weekly performance reports.
- Get AI recommendations for future study plans.

Everything is stored securely so students can continue their preparation anytime.

---

# ⚙️ How the System Works

### Step 1: User Registration

The student creates an account using email and password.

↓

### Step 2: Login

The user logs into the application securely.

↓

### Step 3: Create Study Plan

The student enters:

- Exam Name
- Exam Date
- Daily Study Hours

The AI generates a customized study schedule.

↓

### Step 4: Daily Learning

Students:

- Study topics
- Mark completed chapters
- Track progress

↓

### Step 5: AI Assistance

Students can ask questions such as:

- Explain DBMS
- What are React Hooks?
- Give Python Interview Questions
- Explain Binary Tree

The AI instantly provides explanations.

↓

### Step 6: Practice Tests

Students generate MCQs for any subject.

After completing the quiz, the system shows:

- Score
- Correct Answers
- Wrong Answers
- Accuracy Percentage

↓

### Step 7: Performance Analysis

The dashboard analyzes:

- Study Hours
- Quiz Accuracy
- Completed Topics
- Weak Subjects
- Overall Progress

↓

### Step 8: Weekly Report

The system generates a report showing:

- Hours Studied
- Topics Completed
- Pending Topics
- Improvement Suggestions
